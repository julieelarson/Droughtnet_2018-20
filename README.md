**Data from: Experimental grazing and rainfall manipulations reveal rangeland responses dependent on interannual variation and local species composition**



This repository contains data used to conduct analyses and create figures included in the following manuscript:

Experimental grazing and rainfall manipulations reveal rangeland responses dependent on interannual variation and local species composition. Accepted, Agriculture, Ecosystems & Environment.

This study analyzes how rangeland vegetation and related functions responded to a three-year factorial field experiment manipulating seasonal grazing (ungrazed, growing-season grazing, or dormant-season grazing) and rainfall (ambient growing season rainfall, dry treatment (66% reduction) or wet treatment (66% addition).


The repository includes the following datasets:

**(1) Site_Climate&Treatment_Info_2018-20.csv**
- This file contains a record of daily observed and estimated temperature and precipitation metrics for the site.
- Each row represents one day of the study period.

**(2) Soil_VWC_2018-20.csv**
- This file contains observed soil volumetric content values sampled over the study period.
- Each row represents an observation per sampled plot and day.

**(3) Plant_Plot_Metrics_2018-20.csv**
- This file contains standing plant biomass and bare soil cover estimates sampled over the study period.
- Each row represents observations per sampled plot and study year.

**(4) ForageQuality_2020.csv**
- This file contains forage quality variables used in analysis (crude protein, digestible energy, relative feed value). 
- Each row represents observations per sampled plot in 2020.

**(5) Plant_Plot_Cover_AreaClipped_2018-20.csv**
- This file contains absolute cover values for all individual plants mapped within each plot in each study year.
- Each row represents an observation for an individual plant recorded for each plot and study year. Mutiple plants of the same species were often recorded within the same plot.
- Species diversity estimates were based on summaries of aggregated cover values for each species within each plot and study year.
- Functional group cover estimates were based on aggregated cover values of plants within each functional group for each subplot and study year.

**(6) GreennessCurveMetrics_2020.csv**
- This file contains forage greenness variables used in analysis (day of peak greenness, growing season length).
- Each row represents observations per sampled plot in 2020.
